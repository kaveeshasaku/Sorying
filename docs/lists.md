## Lists

### `LinkedList.SingleLinkedList`

- **Public class**: `SingleLinkedList`
- **Public methods**:
  - `public void addNode(int data)`
  - `public void display()`

Notes: Simple singly-linked list storing `int` values.

Example:
```java
LinkedList.SingleLinkedList s = new LinkedList.SingleLinkedList();
s.addNode(10);
s.addNode(25);
s.display();
```
